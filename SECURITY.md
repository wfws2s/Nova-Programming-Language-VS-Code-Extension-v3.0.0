# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Nova (e.g. interpreter memory corruptions, sandbox escape, crashes on malicious AST), please help us keep the project safe by reporting it responsibly.

1. **Do NOT open a public GitHub issue.**
2. Send an email to the maintainers or open a [Private Security Advisory](https://github.com/nova-lang/nova/security/advisories/new) on GitHub.
3. Include details, proof-of-concept script, and environment info.
4. We will acknowledge receipt within 48 hours and work on a fix promptly.
